# carousel 덱 다루기

덱은 1080×1350 슬라이드 여러 장을 담은 JSON 이다. 이 폴더의 `carousel.mjs` 로 받고 올린다. 올리면 사용자가 열어 둔 편집기에 바로 반영된다.

```sh
node carousel.mjs list                 # 내 덱 목록: id, 장 수, 수정 시각, 제목
node carousel.mjs get <id> deck.json   # 받기
node carousel.mjs put deck.json        # 고친 것 올리기
node carousel.mjs new deck.json        # 새 덱으로 올리기
```

토큰이 없다고 나오면 사용자에게 웹앱 홈의 **AI 연결**에서 토큰을 발급해 `CAROUSEL_TOKEN` 환경 변수나 `~/.config/carousel/token` 파일에 넣어 달라고 한다.

## 작업 순서

1. `list` 로 덱을 찾고 `get` 으로 받는다. 새로 만들 땐 아래 형식으로 파일을 쓴다.
2. JSON 을 고친다. `id`·`updated_at` 은 건드리지 않는다.
3. `put` 으로 올린다. "다른 곳에서 바뀌었어요"가 나오면 사용자가 그사이 편집기에서 고친 것이다. 다시 `get` 해서 그 위에 고친다(덮어쓰지 않는다).
4. 결과 이미지는 여기서 볼 수 없다. 올린 뒤 사용자에게 편집기에서 확인해 달라고 한다.

## 형식

```jsonc
{
  "id": "…", "updated_at": "…",       // get 이 채운다
  "title": "버스앱 리뷰 2편",           // 내보낸 파일 이름이 된다
  "caption": "게시물 본문\n\n#해시태그", // 인스타 게시물 글
  "watermark": "@아이디",               // 읽기 전용(계정 설정). 고쳐도 반영 안 됨
  "slides": [                          // 장 순서대로
    {
      "layers": [                      // 앞에 있을수록 뒤에 깔린다
        { "type": "text", "x": 80, "y": 150,
          "style": "body",              // body(40px) | caption(30px 회색, 출처용)
          "color": "black",             // black | red · 상자 전체 색
          "align": "left",              // left | center | right · 여러 줄일 때 줄 정렬
          "text": "첫 줄\n**굵게** ==빨강== __밑줄__ ||블러||" },
        { "type": "image", "src": "assets/…", "nw": 1736, "nh": 3528,
          "x": 560, "y": 300, "w": 480, "h": 975,
          "crop": { "x": 0, "y": 0, "w": 1, "h": 1 } }
      ]
    }
  ]
}
```

- 좌표는 캔버스 px(가로 1080, 세로 1350). 캔버스 밖으로 걸쳐도 되고 밖은 잘린다.
- 각 장 하단 가운데 약 1290~1340px 에 워터마크와 장 번호가 자동으로 들어간다. 그 자리는 비워 둔다.
- 텍스트
  - 글꼴은 Pretendard 하나, 굵기는 보통·굵게만, 크기는 본문 40·캡션 30 고정이다. 크기를 바꿀 방법은 없다.
  - 상자 너비는 내용에 맞춰진다. 줄은 `\n` 으로 직접 나눈다(한 줄에 한국어 20자 안팎이 읽기 좋다). 캔버스 오른쪽 끝에 닿을 때만 단어 단위로 접힌다.
  - 줄 간격은 57.6px(본문). 여러 줄 상자의 높이는 대략 줄 수 × 57.6.
  - 강조는 `**굵게**`, `==빨강==`, `__밑줄__`. 빨강은 핵심 한두 곳에만 쓴다. `||블러||` 는 글자를 흐리게 가린다(스포일러·민감한 말).
  - 편집기의 배치 기준: 왼쪽 x=80, 오른쪽은 오른쪽 끝이 1000, 가운데는 중심이 540.
- 이미지
  - **새 이미지는 이 스크립트로 넣을 수 없다.** 덱에 이미 있는 이미지(`src`)를 옮기거나(`x`·`y`), 크기를 바꾸거나(`w`·`h`, 비율 유지는 `h = w × (crop.h × nh) ÷ (crop.w × nw)`), 자르거나(`crop`: 원본 대비 0~1 비율), 다른 장에 다시 쓸 수 있다. 새 이미지가 필요하면 사용자에게 편집기에서 넣어 달라고 한다.
- 레이어에 `id` 가 있으면 그대로 둔다. 새 레이어엔 안 적어도 된다.
