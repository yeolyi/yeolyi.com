# 아이폰 프레임 씌우기

```sh
uv run skills/iphone-frame/frame.py <스크린샷...> -o <출력 폴더> [--highlight 파일이름:x,y,w,h ...] [--keep-dupes]
```

- 결과: `<원래 이름>-frame.png`, 1736×3528 투명 PNG(프레임 밖은 투명). 캐러셀에 넣으면 `nw: 1736, nh: 3528`.
- 스크린샷은 1179×2556(아이폰 15·16 Pro 등)에 맞춰져 있다. 화면 자리는 프레임 안 (90, 77)–(1646, 3451)이고 비율이 같아 늘어나지 않는다.
- **중복 걸러 내기**: 시계·배터리만 다른 거의 같은 스크린샷은 앞의 것만 만들고 "거의 같아서 건너뜀"으로 알려 준다. 같은 화면을 흐름에 두 번 쓰는 경우(처음 화면으로 되돌아옴 등)는 만든 이미지를 두 번 쓰면 된다. 모두 만들려면 `--keep-dupes`.
- **강조**: `--highlight IMG_5232.PNG:1118,1050,58,682` 처럼 스크린샷 픽셀 좌표로 영역을 주면 빨간(#EE220C) 둥근 테두리를 그린다. 스크롤바, 숨겨진 버튼처럼 짚어 줄 곳에 쓴다. 좌표는 스크린샷을 Pillow 로 열어 찾는다(예: 오른쪽 끝 회색 세로 막대 = 스크롤바).

## 순서

1. AirDrop 으로 받은 스크린샷은 `~/Downloads` 에 `IMG_xxxx.PNG` 로 들어온다. 수정 시각 순으로 모아 한 장짜리 미리보기(축소해서 나란히)를 만들어 흐름과 중복을 먼저 본다.
2. 강조할 곳의 좌표를 찾는다.
3. 위 명령으로 프레임을 씌운다. 출력은 덱의 `assets/` 로 바로 내도 된다(`decks/<폴더>/assets`).
4. 캐러셀에서는 프레임 이미지를 캔버스 밖으로 걸치거나 `crop` 으로 위·아래만 잘라 쓰기도 한다(예전 컨텐츠에서 자주 쓴 배치).

## 에셋

- `assets/iphone-frame.png`: Figma Community 파일 "iPhone mockups (Community)"의 프레임 이미지 중 하나(1736×3528, 어두운 티타늄). 다른 색·기종은 같은 파일에 있다. 프레임을 바꾸면 `frame.py` 가 화면 자리를 다시 재서 `SCREEN` 과 다르면 멈춘다.
