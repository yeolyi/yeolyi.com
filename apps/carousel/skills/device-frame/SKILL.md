# 기기 프레임 씌우기

```sh
uv run skills/device-frame/frame.py <스크린샷...> -o <출력 폴더> [--device iphone|ipad|watch|macbook|imac] [--highlight 파일이름:x,y,w,h ...] [--keep-dupes]
```

uv 가 패키지를 못 받는 환경이면 Pillow 가 있는 `python3` 로 그대로 돌려도 된다.

| 기기      | 결과 크기 | 화면 자리              | 맞는 캡처                                     |
| --------- | --------- | ---------------------- | --------------------------------------------- |
| `iphone`  | 1736×3528 | (90, 77)–(1646, 3451)  | 1179×2556 = 393×852pt @3x                     |
| `ipad`    | 1812×2550 | (72, 72)–(1740, 2476)  | 1640×2360 = 820×1180pt @2x                    |
| `watch`   | 612×1104  | (30, 216)–(582, 888)   | 41~46mm·Ultra 캡처(352×430 ~ 416×496)         |
| `macbook` | 4200×2530 | (372, 64)–(3828, 2298) | 3456×2234 = 1728×1117pt @2x (MacBook Pro 16") |
| `imac`    | 4640×3588 | (80, 80)–(4560, 2600)  | 4480×2520 = 2240×1260pt @2x (iMac 24")        |

- 결과는 `<원래 이름>-<기기>.png`, 프레임 바깥은 투명이다. 캐러셀에 넣으면
  `nw`·`nh` 가 위 결과 크기다.
- `--device` 를 안 주면 방향이 같고 `frames.json` 의 `auto` 조건(폭·비율
  허용치)을 지키는 기기 중 비율이 가장 가까운 것을 고른다(웹 /frame 과 같은
  규칙. 웹은 맞는 기기가 없으면 브라우저 창). 가로 아이폰·아이패드처럼 파일에
  없는 모양은 지원하지 않는다.
- 화면 자리와 비율이 다르면 빈틈없이 채우고 넘치는 쪽을 자른다(위아래는 위 기준,
  좌우는 가운데 기준).
- **웹 화면을 찍을 때**: Playwright 로 위 pt 크기 뷰포트·배율로 찍는다.
  넘침(가로 스크롤)을 보여 줘야 하면
  `chromium.launch({ ignoreDefaultArgs: ["--hide-scrollbars"] })` 로 스크롤바를
  켜고 `isMobile: false` 로 찍는다(모바일 에뮬레이션은 스크롤바를 숨긴다).
- **중복 걸러 내기**: 시계·배터리만 다른 거의 같은 스크린샷은 앞의 것만 만들고
  "거의 같아서 건너뜀"으로 알려 준다. 모두 만들려면 `--keep-dupes`.
- **강조**: `--highlight IMG_5232.PNG:1118,1050,58,682` 처럼 스크린샷 픽셀
  좌표로 영역을 주면 빨간(#EE220C) 둥근 테두리를 그린다.

## 순서

1. AirDrop 으로 받은 스크린샷은 `~/Downloads` 에 `IMG_xxxx.PNG` 로 들어온다.
   수정 시각 순으로 모아 한 장짜리 미리보기(축소해서 나란히)를 만들어 흐름과
   중복을 먼저 본다.
2. 강조할 곳의 좌표를 찾는다.
3. 위 명령으로 프레임을 씌운다.
4. 덱에 넣을 땐 carousel 스킬의 `upload` 로 올리고 나온 `src`·`nw`·`nh` 를
   이미지 레이어에 쓴다. 프레임을 캔버스 밖으로 걸치거나 `crop` 으로 위·아래만
   잘라 쓰기도 한다.

## 에셋

- `assets/iphone-frame.png`: Figma Community "iPhone mockups (Community)"의
  프레임(어두운 티타늄).
- `assets/ipad-frame.png`: Figma Community "Apple Frames (Community)"의
  `iPad_gray_2x` 프레임. 내보낸 PNG 의 캔버스 배경과 화면 자리를 투명으로
  뚫었다(화면 모서리 반지름 36).
- `assets/macbook-frame.png`·`imac-frame.png`·`watch-frame.png`: 같은 파일의
  `Macbook_gray_2x`·`iMac_gray_x2`·`Apple_watch_gray_3x`(스포츠 밴드). 내보내기
  대신 .fig 를 풀어 도형(둥근 사각형·타원·경로, 변환·마스크 포함)을 그대로 다시
  그렸다. iPad 로 대조하면 Figma 내보내기와 같다. 화면 자리(위 모서리
  반지름 80)는 투명, 노치는 화면 위에 남는다.
- 프레임을 바꾸면 `frame.py` 가 화면 자리를 다시 재서 `DEVICES` 와 다르면
  멈춘다.
