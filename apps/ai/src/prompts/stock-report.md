지금까지 나눈 대화를 근거로, 나라는 사람이 주식시장에 상장된 기업이라고 가정하고
증권사 종목 분석 보고서(Company Report) 두 장을 만들어 줘. 생김새는 맨 아래 HTML
틀이 정한다. 너는 틀 맨 위 `R` 객체의 값만 채운다. 실제 국내 증권사 리포트처럼
진지하게, 내용만 웃기게.

# 재료

- 근거는 오직 나와 나눈 대화다. 내가 자주 쓰는 말, 반복해서 시키는 일, 고치라고
  한 것, 짜증 낸 것, 집착하는 것을 찾는다.
- 대화 기록을 읽을 수 있으면(Claude Code 라면 ~/.claude/history.jsonl 등) 실제로
  센다. 못 세면 그럴듯하게 추정하고 출처 줄에 "당사 추정"이라고 적는다.
- 인용은 내가 실제로 한 말을 그대로, 따옴표로. 지어낸 말을 내 말처럼 쓰지
  않는다.
- 일반론("성실하다", "호기심이 많다") 금지. 이 사람만의 구체적인 습관이 웃음
  포인트다.

# 숫자를 금융 지표로

- 상장일 = 첫 대화 날짜, 발행주식수 = 지금까지 보낸 메시지 수, 일평균 거래량 =
  하루 평균 메시지, 52주 최고 = 가장 많이 보낸 날, 주가 = 기간별 메시지 수.
- 목표주가·현재주가·시가총액도 실제 숫자에서 계산한다(예: 목표주가 = 피크 월
  메시지 × 12). 계산식은 targetNote 에.
- 핵심 사업 = 가장 많이 한 일, 경쟁력 = 남보다 실제로 나은 점(과대평가 금지),
  위험 요인 = 치명적 단점(신랄하게), 주가 추이의 표시점 = 행동이 바뀐 사건(새
  도구 도입, 급락, 공백 등).
- 말버릇별 거래량 = 가장 많이 쓴 말 상위 10개. 가장 큰 막대는 자동으로 주황, hi
  에 적은 하나(이 사람을 대표하는 말)는 검정.

# 문체

- 실제 증권사 리포트 말투: "~다"로 끝나는 건조한 문장, "유지한다", "판단한다",
  "보인다". 감탄사·이모지·ㅋㅋ 없음. 진지할수록 웃기다.
- 대표 발언은 "대표 공시는 …", 반복 요청은 "…를 공시한다"처럼 공시·실적·가이던스
  같은 증권 용어로 비튼다.
- 장점은 깎아서, 단점은 정확하고 신랄하게. 다만 인신공격이 아니라 행동을 근거로.
- 회사·도구·사람 이름 중 내 직장 내부 것(사내 시스템, 동료 이름 등)은 일반
  명사로 바꾼다.

# 만드는 방법

- 아래 틀을 글자 하나 바꾸지 말고 그대로 쓰고, `const R = {` 부터 `};` 까지만 내
  내용으로 바꾼다. 틀의 R 에 적힌 값은 각 칸에 무엇을 넣을지 설명이다. 배열
  길이는 주석을 따른다.
- 아티팩트·캔버스·파일을 만들 수 있으면 HTML 하나로 만들어 띄운다. 인쇄(PDF
  저장)하면 A4 두 장이 된다.
- 두 장 안에 들어가게 쓴다. 넘치면 본문 문장을 줄인다.
- HTML 을 못 띄우는 곳이면 같은 내용을 마크다운(표 포함)으로 쓴다.

답하기 전에 스스로 점검: 숫자에 근거가 있나, 인용이 내가 실제로 한 말인가,
일반론이 섞이지 않았나.
