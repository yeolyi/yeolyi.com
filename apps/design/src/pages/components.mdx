구조나 동작이 있는 것은 컴포넌트로 둡니다. 글(MDX)에서도 같은 컴포넌트를 씁니다.

## 버튼

주황 버튼은 한 화면에 하나만 씁니다. 호버하면 반전되고, 누르면 내용물이 살짝
내려갑니다. 아이콘 하나로 뜻이 통하면 테두리 없이 아이콘만 둡니다.

<ButtonDemo client:visible />

## 입력

라벨, 설명, 칸 순서로 위에서 아래로 좁게 붙여 둡니다.

<InputDemo client:visible />

## 날짜 입력

생년월일, 전입일처럼 이미 아는 날짜는 달력 대신 연도, 월, 일 세 칸에 숫자로
넣습니다.

<DateInputDemo client:visible />

## 체크박스

켜고 끄기. 켜지면 사각형이 채워집니다(체크 표시 없음). 라벨을 눌러도 켜집니다.

<CheckboxDemo client:visible />

## 라디오

여럿 중 하나. 넷을 넘으면 셀렉트를 씁니다. 짧은 라벨은 붙은 칸(세그먼트)에서
고른 칸만 반전합니다.

<RadioGroup
  client:visible
  options={["자동", "밝게", "어둡게"]}
  aria-label="테마"
/>

라벨이 길거나 질문의 답을 고를 때는 세로로 한 줄에 하나씩 둡니다.

<RadioGroup
  client:visible
  orientation="vertical"
  options={["혼자", "배우자 또는 결혼할 사람과 함께"]}
  aria-label="함께 신청하는 사람"
/>

## 셀렉트

고를 게 다섯 이상일 때. 입력 칸과 같은 상자에 오른쪽 끝 화살표, 열리면 같은 폭의
목록이 나옵니다. 고른 것엔 체크, 가리킨 것은 반전에 왼쪽 주황 막대.

<Select
  client:load
  aria-label="명령어"
  defaultValue="ADD"
  options={["ADD", "SUB", "JMP", "LOAD", "STORE"].map((v) => ({
    value: v,
    label: v,
  }))}
/>

## 슬라이더

값 조절. 선 어디를 눌러도 그 자리로 옮겨 갑니다. 값은 옆에 고정폭으로 둡니다.

<SliderDemo client:visible />

## 접기

접힌 내용은 오른쪽 화살표, 펼치면 아래로 돌아갑니다. 상자 없이 아이콘과 글자만.
`@yeolyi/ui/Details` 의 `Details`, `Summary` 를 씁니다. 글(MDX)에서는 import
없이 `<Details><Summary>…</Summary>…</Details>` 로 씁니다.

<Details>
<Summary>풀이 보기</Summary>

NAND 하나로 NOT, AND, OR을 모두 만들 수 있습니다.

</Details>

## 표

세로선 없이 헤더 아래만 굵은 선입니다.

| 형식    | 색공간 |
| ------- | ------ |
| `rgb`   | sRGB   |
| `oklch` | OKLab  |

## 글 요소

### 인용

왼쪽에 2px 굵은 선, 글자는 보조 색입니다.

> 내 언어의 한계는 내 세계의 한계를 의미한다.

### 강조

문장 안 강조는 **굵게** 하나입니다. 색이나 바탕은 바꾸지 않고, 기울임은 쓰지
않습니다.

### 코드

고정폭에 옅은 바탕, 왼쪽 2px 굵은 선입니다.

```css
color: oklch(0.649 0.299 29);
```

### 이미지

본문 폭에 꽉 채우고, 설명은 조금 띄워 아래 보조 색으로 둡니다.

<figure>
  <img src={example.src} width={example.width} height={example.height} alt="" />
  <figcaption>720×360 예제 이미지</figcaption>
</figure>

### 목록

글 속 목록의 불릿은 고정폭 \*입니다.

- 목록 하나
- 목록 둘

## 데모 상자

글 속에서 만져 볼 수 있는 것은 1px 가는 선 상자로 두르고, 왼쪽 위에 고정폭으로
"데모"라고 적습니다. 이 페이지의 예제가 모두 이 상자 안에 있습니다.
