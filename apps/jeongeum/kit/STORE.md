# 정음 — 크롬 웹 스토어 제출 메모

## 올리는 순서 (PC에서)
1. `chrome://extensions` → 개발자 모드 켜기 → **압축해제된 확장 프로그램 로드** → `monttang` 폴더 선택해서 먼저 써 보기
2. https://chrome.google.com/webstore/devconsole 접속 → 개발자 등록(일회성 등록비) 
3. **새 항목** → `jeongeum-1.0.0.zip` 업로드 (이미 올렸다면 패키지 탭에서 새 zip으로 교체)
4. 아래 내용 붙여 넣기 → 이미지 올리기 → 검토 제출

## 스토어 등록정보
- **이름**: 정음 — 외국어를 한글 소리로 (manifest에 들어 있어 자동으로 채워져요)
- **요약** (zip 안 manifest에서 자동으로 채워짐): 웹페이지의 영어·일본어·중국어를 모두 한글 소리로 바꿔 보여 줍니다. Hello → 헬로, 東京 → 동경, 北京 → 베이징
- **카테고리**: 라이프스타일 → 재미 (Just for Fun)
- **언어**: 한국어

**설명**
```
훈민정음, '백성을 가르치는 바른 소리'에서 이름을 따온 한글날 기념 확장 프로그램입니다.
켜 두면 보고 있는 웹페이지의 외국 글자를 모두 한글 소리로 바꿔 보여 줍니다.

• 영어: 발음사전 6만 단어를 바탕으로 자연스럽게 — Hello, world! → 헬로, 월드!
• 약어는 알파벳 이름으로 — API → 에이피아이
• 일본어: 가나는 외래어 표기법대로, 한자는 우리 한자음으로 — 東京 → 동경
• 중국어: 중국어 발음대로 — 北京 → 베이징
• 숫자도 읽을 수 있습니다(선택) — 2026 → 이천이십육

팝업에서 언제든 켜고 끌 수 있고, 끄면 페이지가 원래대로 돌아옵니다.
사이트별로 끌 수도 있습니다.

입력창, 코드 블록, 편집 중인 글은 바꾸지 않습니다.
모든 변환은 브라우저 안에서만 이루어지며, 어떤 정보도 외부로 보내지 않습니다.
```

## 개인정보 보호 탭
- **단일 목적**: 사용자가 보고 있는 웹페이지의 외국 문자(영어·일본어·중국어 등)를 한글 음차로 바꿔 표시합니다.
- **storage 권한 사유**: 켜기/끄기, 숫자 읽기 여부, 꺼 둔 사이트 목록 같은 사용자 설정을 저장하는 데만 씁니다.
- **호스트 권한(모든 사이트, content script) 사유**: 사용자가 방문하는 어느 웹페이지에서든 글자를 바꿔 보여 주는 것이 이 확장 프로그램의 유일한 기능이라, 모든 페이지의 텍스트에 접근해야 합니다. 페이지 내용은 브라우저 안에서만 변환하며 저장하거나 전송하지 않습니다.
- **원격 코드 사용**: 아니요 (사전 데이터까지 전부 패키지에 포함)
- **데이터 사용**: 어떤 사용자 데이터도 수집하지 않음 → 모든 항목 체크 해제, 세 가지 인증 문구에 체크
- **개인정보처리방침 URL**: 데이터를 수집하지 않으면 필수는 아니지만, 요구하면 깃허브 README에 "수집하는 정보 없음" 한 줄 적고 링크

## 알아 둘 점
- "모든 사이트 접근"이라 심사가 보통보다 길 수 있어요(며칠~1주).
- 사전 파일이 약 1.5MB라 페이지마다 한 번 읽어요. 체감 지연은 거의 없지만, 느린 PC면 끄고 쓰는 사이트를 늘리면 돼요.
